# ExecPlan v2-0011 — レーダーのプライバシー掲載方針

## 目的（2026-11-26）

最新のレーダー収集記事に含まれた個人名を掲載文から除き、今後の生成にも一般参加者・児童生徒の実名非掲載のルールを適用する。この計画・テスト・コミットメッセージには対象者の氏名を記録しない。

## 方針

- 既存記事は氏名と所属校を省き、選考結果と販売予定を紹介する。ID・日付・元情報URLを維持する。
- prompts/collect-latest.mdを掲載ポリシーの設定箇所とし、title / summary / source.name / researchSources[].titleすべてに一般の参加者・応募者や児童・生徒の実名非掲載を指示する。未成年者の所属校・学年も省く。
- 役割・立場への言い換えでは正確に紹介できない候補、URL自体に掲載対象外の実名を含む候補は除外する。元URLを書き換えない。
- 公開活動に使うハンドルネーム・クリエイター名・芸名や店舗名などは紹介に必要な範囲で掲載可能。判断に迷う名前は役割で表現し、本名の調査・別アカウントとの結び付けはしない。ユーザーとの相談でこの範囲に合意。
- AIへの指示は人名の機械的な検出保証ではない。独自の不完全な人名辞書・正規表現や追加依存は導入しない。
- ユーザーはGit履歴からの削除とforce pushを明示的に希望。対象コミットを親に持たない修正版を準備する。リモートの保護設定を確認し、履歴置き換えの可否を記録する。GitHubのキャッシュ・他者のcloneまで消去できるとは扱わない。

## 履歴削除の制約

GitHub APIでmain-protectionを確認。non_fast_forward禁止、bypass_actorsなし、current_user_can_bypassはnever。main-owner-reviewもPR経由が必須。保護設定の変更やmainへのforce pushは実施しない。修正専用ブランチは問題コミットの親から作り、問題コミットを祖先に含めない。mainの履歴および公開サイトへの反映は未完了で、所有者による履歴削除手順の調整が必要。
