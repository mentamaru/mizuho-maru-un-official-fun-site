# ExecPlan 0006 — お問い合わせと運営案内

## 背景と目的

利用者がお問い合わせフォームへ確実に移動できるようにし、サイトの運営目的と運営者の背景を現在の方針に合わせて明確にする。あわせて、非公開中のGitHubリポジトリへ直接遷移させず、公開予定を説明する案内ページを用意する。

## スコープ

- 指定されたGoogleフォームへのお問い合わせ導線。
- 「このサイトについて」と「運営者について」の本文更新。
- GitHub用のワンクッションページと、フッター導線の変更。
- 上記の導線と文言を確認するE2Eテスト。

## 非スコープ

- Googleフォームの設問・権限設定の変更。
- GitHubリポジトリの公開、外部サービスへの設定変更。
- Backend、認証、CMSの追加。

## 実施手順

1. 既存のフッター・補助ページ・お問い合わせ実装を確認し、静的ページだけで完結する変更として設計する。
2. 指定Googleフォームを静的な外部リンクとしてお問い合わせページへ設定する。
3. 運営目的・運営者紹介を更新し、GitHub公開予定を説明するサイト内ページを追加する。
4. フッターのGitHub導線を新ページに切り替え、E2EテストでフォームURLと案内ページを検証する。
5. lint、typecheck、unit test、build、Playwright、および既存Security Checkを実行する。

## 完了条件

- お問い合わせページのボタンが指定Googleフォームを新しいタブで開く。
- 運営目的・運営者紹介が依頼内容に沿った文言になる。
- フッターのGitHub導線が非公開・公開予定を説明する内部ページへ向く。
- 必須ローカル検証が成功する。
